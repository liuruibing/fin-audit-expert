# FinAudit · 金融信披智能审核专家系统 (Harness Framework)

> **把金融垂类大模型，变成一位不知疲倦的审核同事。**  
> 参考行业前沿的 Harness 纪律框架体系，构建面向公募基金、银行理财及券商资管定期报告的**私有化智能审核中台**。

---

## 🌟 核心价值与背景

公募基金年报/中报/季报与银行理财报告具有**“高频、刚需、窗口期极度集中（两周内数百份）、问责到个人”**的特点：
1. **人工复核难全面**：按章节分工，无人核验“全文每一处托管人是否相同”；年年相似的段落整段沿用上一期，极易遗漏年份；
2. **规则软件做不活**：只能捕获固定正则与格式，对“数字抄错”、“主体错乱”、“时点穿越”无能为力；
3. **通用大模型不敢用**：公网调用数据出域违规，且大模型存在不可控的**“幻觉”**，给不出精确出处，无法进入复核流程。

**FinAudit** 的解决之道是：**模型解决理解，Harness 确立纪律，责任与裁决始终在人。**

## 🏗️ 三层架构体系

```mermaid
graph TD
    subgraph 应用层 [应用层 (用得起来)]
        UI1[双栏审核工作台: 发现清单 + 原文逐字高亮]
        UI2[专家一键裁决: 真缺陷 / 误报留痕]
        UI3[审核专家 Copilot: 对着报告直接问出处]
        UI4[价值回执大屏: 拦了多少、省了多少]
    end

    subgraph 框架层 [Harness 框架体系 (靠得住)]
        H1[有据才报 Grounding: 无原文坐标直接剔除]
        H2[分级分列: 实质性错误 vs 格式疑点]
        H3[符号数学执行引擎: 份额加总/净值勾稽算平]
        H4[自动化回归重放验证器: 确保越用越准]
    end

    subgraph 底座层 [底座模型层 (看得懂)]
        M1[Qwen2.5-32B 私有化部署]
        M2[版面与坐标解析引擎: MinerU / PyMuPDF]
        M3[专家裁决金标语料微调]
    end

    应用层 <--> 框架层
    框架层 <--> 底座层
```

1. **底座层（看得懂）**：
   * 采用 Qwen2.5-32B（或 14B）私有化部署，读懂金融公告术语，完成结构化事实抽取。
2. **框架层（靠得住 - Harness 框架）**：
   * **有据才报**：上报的每一条问题必须附带原文出处，找不到精确物理坐标一律物理抛弃（100% 阻断幻觉）；
   * **符号计算**：财务勾稽计算由底层 Python 代码执行，模型不进行心算；
   * **分级分列**：实质性硬伤（标红阻断）与格式建议（标灰）清晰切分。
3. **应用层（用得起来）**：
   * 极简直观的前端双栏交互，左侧点问题，右侧原版面即刻滚动高亮。

## 🚀 快速上手与运行

### 1. 环境准备
推荐 Python 3.10+：
```bash
pip install -r requirements.txt
```

### 2. 运行自动化回归重放验证 (Benchmark)
验证系统如何在长文档中**准确捕获实质性缺陷**并**100% 拦截大模型虚构的幻觉用例**：
```bash
python scripts/run_benchmark.py
```

### 3. 运行单元测试
```bash
PYTHONPATH=. pytest -v
```

### 4. 启动审核工作台
```bash
chmod +x scripts/run_dev.sh
./scripts/run_dev.sh
```
启动后在浏览器打开：**`http://127.0.0.1:8080`** 即可体验完整的双栏审阅工作台。

## 🖥️ 核心交互功能演示

1. **双栏联动逐字高亮**：
   * 点击左侧清单中的任一卡片（如“托管人主体名称前后矛盾”），右侧原版面瞬间翻至第 4 页，并平滑滚动到对应句子，黄色/红色矩形光标高亮闪烁。
2. **专家一键裁决留痕**：
   * 点击 **【真缺陷】** 或 **【误报】**，系统即时留痕并记录裁决人、时间、理由，自动沉淀至金标库。
3. **审核专家·对话答疑 (Copilot)**：
   * 点击右下角“咨询审核专家”，可直接向大模型提问：“*为什么把第 1 条判为问题？依据是什么？*”，专家基于 Harness 证据链生成严谨带页码的回复。
4. **价值回执大屏**：
   * 切换至“价值回执”Tab，实时查看全局审核篇数、拦截实质缺陷数、单篇平均耗时及裁决数据沉淀。

## 🔒 私有化一体机与信创部署

支持金融机构机房无外网（离线）部署：
* **标准一体机配置**：2U 机架式服务器 + 2 张 RTX 4090D 24G（或 L40S 48G），采用 `docker-compose.yml` 一键交付。
* **国产信创适配**：支持华为昇腾 910B / 麒麟 KylinOS 离线部署，模型采用 Qwen2.5-32B-AWQ 量化版本，单篇 100 页报告解析审核仅需约 1~2 分钟。
